# Number Guessing Game

A simple Python game where the computer picks a random number and you have to guess it!

## What it does:
- Computer picks a random number between 1 and 100
- You guess the number
- It tells you if you're too high or too low
- Keep guessing until you get it right!

## How to run:
1. Make sure you have Python installed
2. Run `python number-guessing-game.py`
3. Start guessing!

## What I learned:
- Using the `random` module
- Generating random numbers with `randint()`
- Game loops with `while True`
- Input validation and comparisons
